The test derives "core_gems" by grepping Redmine’s Gemfile for every gem declaration (regex /^gem .../), then asserts that all of them are present in the current Bundler definition. This mixes groups: it picks up development-only gems from core (e.g., byebug, webdrivers) that are not installed in the current test groups (:default, :test), causing false failures unrelated to the plugin.
Failure scenario: Run the plugin test suite against Redmine 7.0 where the core Gemfile includes development-only gems. The assertion `assert_empty core_gems - bundled` fails because those dev gems are not in Bundler.definition for the test run.
